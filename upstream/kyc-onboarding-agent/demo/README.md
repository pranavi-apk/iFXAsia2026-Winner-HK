# Demo documents

No sample documents ship with this repository.

The assessment pipeline expects a case folder of PDFs covering the typical
institutional-investor onboarding pack:

| # | Document | Used for |
|---|---|---|
| 01 | Certificate of incorporation | Entity existence, jurisdiction |
| 02 | Constitutional documents | Entity type, authorised signatories |
| 03 | Audited financial statements | Financial standing |
| 04 | Subsidiaries / group structure | UBO chain extraction |
| 05 | Officer certifications | Authorised persons |
| 06 | Business bank statement | Source of funds |
| 07 | Beneficial owner bank statement | Source of wealth |
| 08–09 | Beneficial owner photo ID | Identity verification |

Supply your own test pack — ideally clearly-synthetic documents that do not
reference real individuals or entities.
