# the global bank KYC Onboarding Demo - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### 1. Access the Application

**Open in your browser:**
```
http://localhost:8080
```

### 2. Explore the Dashboard

You'll see:
- 📊 Key metrics at the top (Total Cases, Pending, High Risk, Completion Rate)
- 📋 Active cases table with all investor cases
- 🔍 Search and filter options
- ➕ "Create New Case" button

### 3. Create Your First Case

**Quick Steps:**
1. Click **"Create New Case"** button
2. Fill in investor details:
   - **Investor Name**: e.g., "Acme Investment Fund"
   - **Entity Type**: Select from dropdown
   - **Country**: Country of incorporation
   - **Industry**: Business sector
3. Click **"Create"**
4. You're redirected to the case details page!

### 4. Upload Documents

**Easy Document Upload:**
1. In your case, click **"Documents"** tab
2. Click **"Upload Documents"** button
3. Drag & drop files or click to browse
4. Accepted formats: PDF, JPG, PNG, DOCX (max 50MB)
5. AI automatically classifies documents! ✨

### 5. Review Case Details

**Explore the tabs:**
- **Overview**: Investor profile and risk summary
- **Documents**: All uploaded documents with AI analysis
- **Completeness**: Document checklist and progress
- **Authenticity**: AI-powered verification results
- **Audit Trail**: Complete activity history

## 🎯 Common Tasks

### Task: Find a Specific Case
1. Use the search bar at the top
2. Type investor name or case ID
3. Press Enter or click search

### Task: Filter Cases by Risk Level
1. Click the "Risk Level" dropdown
2. Select desired level (Low, Medium, High, Critical)
3. Table updates automatically

### Task: Download Documents
1. Open a case
2. Go to Documents tab
3. Click on document thumbnail
4. Click "Download" button

### Task: Mark Case as Reviewed
1. Open the case
2. Review all tabs
3. Click "Update Status" button
4. Select new status
5. Add notes (optional)
6. Click "Save"

## 📖 Understanding Risk Levels

| Risk Level | Color | Meaning | Action Required |
|------------|-------|---------|-----------------|
| 🟢 **Low** | Green | Standard due diligence | Streamlined approval |
| 🟡 **Medium** | Yellow | Some concerns | Standard review |
| 🟠 **High** | Orange | Multiple risk factors | Enhanced due diligence |
| 🔴 **Critical** | Red | Severe risk | Senior review required |

## 🆘 Quick Troubleshooting

### Can't upload a document?
- ✅ Check file size (must be < 50MB)
- ✅ Verify file format (PDF, JPG, PNG, DOCX only)
- ✅ Try refreshing the page
- ✅ Use Chrome or Firefox browser

### AI classification wrong?
- Click the document
- Select "Override Classification"
- Choose correct type
- System learns from your feedback!

### Case not showing up?
- Clear all filters
- Check the status filter
- Use search with case ID
- Refresh the page
